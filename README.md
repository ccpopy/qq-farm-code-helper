# 农场 Code 获取助手

一个面向 Windows 桌面客户端的小型 Rust/Tauri 应用。它会在本机临时启用定向代理，仅处理目标农场网关：透明转发同一次 `/prod/ws` 官方登录，在内存中保留 `code` 并读取官方 `SyncAll` 响应中的好友 GID，随后一起同步到远程服务器。

除一次性 Code 获取外，Helper 还提供默认关闭的“协议模式”：持续透明转发官方网关连接，把每条连接的完整 WebSocket 握手 URL（含 Code）以及双向二进制消息按顺序保存到本机，供登录凭据严格比较、新活动协议审查与回归验证使用。该模式不会上传抓包资料，也不会调用远程服务器接口。

获取后可以：

- 读取 Windows 客户端主界面当前昵称，并以只读方式查询本地登录列表，唯一匹配账号和头像；
- 自动调用服务端项目的账号接口；同一服务器用户下，相同 QQ 号会复用原账号 ID 并更新 Code，只有首次同步才新增账号；同步成功后还会调用启动接口，使已停止的账号无需再手动启动；
- “同步官方好友”默认开启：先完成官方登录并读取好友 GID，随后通过服务器现有批量新增接口写入对应远程账号；
- 或者仅保存在内存中，由用户点击复制。

## 使用流程

1. 在服务器设置中填写上游管理页面地址。
2. 在管理页面左侧边栏底部复制当前登录 Token，填入工具。
3. 点击「测试连接」，确认 `/api/user/me` 可以正常返回当前用户。
4. “同步官方好友”默认开启；如只需要 Code，可在服务器设置中关闭该开关。保存设置并点击「启动获取」。
5. 代理启动后，再打开或登录 Windows 客户端；若客户端已在运行，建议完全退出后重新打开。等待工具显示账号已确认，再进入农场。
6. 工具在同一次官方连接中取得 Code 与好友 GID 后，会立即恢复系统代理、移除临时根证书，再同步 Code、启动远程账号并批量写入好友 GID。

开启好友同步时，本次连接会先透明转发到官方网关，农场可正常完成登录初始化；随后远程账号使用同一个 Code 登录时，本地会话可能收到同账号登录提醒或被下线。关闭好友同步时仍保持仅拦截 Code 的原流程。

### 协议模式

“协议模式”开关位于“本地代理端口”右侧，默认关闭。开启后服务器地址、Token、自动同步和账号绑定均不会参与本次任务：

1. 保存设置并点击“启动协议监听”。
2. 进入 QQ 农场，按需要操作目标活动；监听会持续运行，不会在首次消息后自动停止。
3. 操作完成后点击“停止并恢复网络”。
4. 在 EXE 同目录的 `protocol-captures/session-<时间戳>/` 中审查结果；该目录含明文短期登录凭据，完成比较后请按需安全删除。

每条连接的完整握手 URL 原样保存在 `handshakes/connection-<连接编号>-url.txt`，其中包含明文 Code；`connections.jsonl` 记录连接编号、时间、URL 文件名和大小。每条完整的 WebSocket 二进制消息会在处理帧拆包、客户端掩码和消息分片后保存为按全局收发顺序编号的 `.bin` 文件，`manifest.jsonl` 同时记录对应的 `connection_id`、序号、方向、时间、文件名和大小，`session.json` 记录格式版本和敏感性说明。抓包资料还可能包含账号、好友、农场资产等数据，请仅在可信环境中保存和分析，禁止上传或公开分享。

### 同步官方好友

开启服务器设置中的“同步官方好友”后，Helper 会透明转发官方 WebSocket 登录，并从成功的 `FriendService.SyncAll` 响应中提取、去重好友 GID。若客户端在规定时间内没有触发 `SyncAll`，Helper 会通过当前已认证的官方连接补发一次空 `open_ids` 的 `SyncAll`；官方返回 0 位好友或超时时会明确降级，不会伪报成功。

Code 成功同步并启动远程账号后，Helper 使用同一服务器 Token 和账号 ID 调用 `/api/friend-known-gids/batch-add`，把本次官方响应中的 GID 写入远程已知好友配置。若没有捕获到好友 GID，Code 同步仍会照常完成，并在结果中说明好友同步被跳过。

## 应用更新

- 应用启动后会检查本项目最新的稳定版 GitHub Release，也可以在“应用更新”面板中手动检查。
- Release 下载默认通过 `https://gh.lessdo.top/原始GitHub地址` 加速；关闭“使用 GitHub 加速”后会直接从 GitHub 下载。
- 下载完成后必须通过 GitHub Release API 返回的官方 SHA-256 校验，校验失败不会执行更新包。
- 使用安装版时，会将新版静默安装到当前 EXE 所在目录；例如当前位于 `D:\Tools\QQFarm`，更新仍安装到该目录。
- 使用便携版时，会在程序退出后原地替换当前 EXE。安装前会停止同路径残留进程，完成后自动重新启动。

## 本地身份识别

- 工具通过 Windows UI Automation 读取新版客户端主窗口左上角当前昵称，再与本地登录索引中的 `uin`、`nickName` 和 `faceUrl` 做唯一匹配，不读取聊天数据库。
- `isUserLogin` 和最近活动分区可能指向后台主会话，不能代表界面当前切换的账号，因此不再用于自动绑定。
- 界面每 2 秒自动检测一次切号，并要求连续两次结果一致；切换过程中、昵称同名、主窗口不可读或登录列表尚未刷新时会立即清空旧身份。
- 启动后等待农场登录期间，后端会持续检测客户端身份；新账号连续稳定后会自动替换锁定身份，因此可以先启动获取、再切换目标账号、最后进入农场。
- 捕获 Code 后还会再次确认；若捕获前后的账号仍不一致，则停止自动同步并保留 Code。
- 启用自动同步时，启动前无需登录客户端，可以先启动代理再登录；但捕获 Code 前必须稳定确认目标身份，否则 Code 只保留在内存中且不会请求服务器。若获取期间发生切号，同样停止同步，从而避免创建缺少数字账号的默认记录。
- 若本地检测不可用，关闭自动同步后仍可只获取 Code，但工具不会自动在服务器创建账号。
- 农场 WebSocket 请求本身不包含 UIN、昵称或头像，身份信息不是从 Code 中解码得到的。

## Token 说明

- 请使用上游管理网页侧边栏中的当前登录 Token。
- 工具通过 `x-admin-token` 请求头访问服务器。
- Token 保存在 Windows 凭据管理器，不会写入 `settings.json`。
- 上游服务器重启或 Token 失效时，需要从网页重新登录并复制新 Token。

## 配置与运行文件位置

- `settings.json`、`system-proxy-backup.json`、`temporary-ca.cer` 和 `traffic-diagnostics.log` 均存放在应用 EXE 所在目录，不使用 `%APPDATA%` 默认目录。
- 协议模式的持久化会话存放在 EXE 同目录的 `protocol-captures/`；网络清理和正常退出不会删除这些审查资料。
- 首次运行新版时，会自动把旧版本默认应用数据目录中的上述文件迁移到 EXE 所在目录。
- 便携版可直接放到任意有写入权限的目录；配置和恢复文件会跟随 EXE，移动时可一并迁移。
- 安装版同样将运行文件放在安装目录。若自行选择安装位置，请确保当前 Windows 用户对该目录具有写入权限。
- 服务器 Token 仍由 Windows 凭据管理器加密保存，不会以明文文件放在应用目录。

## 安全边界

- 代理只监听 `127.0.0.1`，不向局域网开放。
- 非目标农场 HTTPS 连接只做 TCP 直通，不解密内容。
- 只有目标农场网关的 `/prod/ws` 登录请求可以触发 Code 提取。
- Code 不写日志、不写配置文件。
- 协议模式不调用服务器同步链路，但会按用户选择保存完整握手 URL（含明文 Code）和完成拆帧后的游戏二进制消息；资料只写入本机会话目录，不进入普通日志，也不会上传。
- 好友同步只解析官方网关返回的 `SyncAll`/`GetGameFriends` 好友 GID；好友姓名、头像和 OpenID 不写日志、不写配置文件，也不会上传。
- 正常退出会恢复原系统代理并移除临时根证书。
- 异常崩溃时会保留代理备份；下次启动会先自动恢复，也可点击「清理代理与证书」。

## 开发与构建

需要 Windows 10/11、Microsoft Edge WebView2 Runtime 和 Rust stable MSVC toolchain。

```powershell
# 开发运行
.\scripts\dev.ps1

# 构建 release EXE
.\scripts\build.ps1
```

产物位于 `release` 目录。Tauri 不内置 WebView2 Runtime，因此程序本体保持较小。
